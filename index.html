Step 1, add following bookmarklet to your bookmarks: Make better ticket

Step 2, go to Bilkom and open tab with tickets

Step 3, expand the ticket you want to use

Step 4, run the bookmarklet (on desktop just click on it, on mobile type the name in the address bar and tap it)

You can generate that bookmarklet yourself. Head over to the Bookmarklet Maker website and paste this code:

if(document.querySelector("#embededTicketObject") !== null) {
  const script = document.createElement("script");
  script.src = "https://tithen-firion.github.io/bilkom-better-ticket/bilkom.js";
  script.integrity = "sha384-1fJt/ca3jWLLxXJVRdVg24wdnbAcg9samxwU2Fk3f6Ed9guPDIVx3nL5nnY/DF1t";
  script.crossorigin = "anonymous";
  document.body.append(script);
}
